Välkommen till Simpel

Din lokala uppgiftshanterare — enkel, snabb och helt offline.

Uppgifter
Skapa uppgifter med prioritet (hög / medel / låg), deadline och projekttag. Tryck Ctrl+Space för att skriva med AI-hjälp.
Kalender
Se alla uppgifter dag för dag. Klicka på ett datum för att filtrera och få en överblick av vad som gäller just den dagen.
Anteckningar
Fri text med inbyggd AI-skrivhjälp. Markera valfri text för att få förslag på förbättringar, förkortningar eller expansioner.
Kanban
Tre kolumner: Att göra / Pågår / Klart. Dra och släpp uppgifter mellan kolumnerna för att följa arbetsflödet.
Avklarade
Alla slutförda uppgifter samlade på ett ställe. Filtrera per projekt för att se vad du åstadkommit över tid.
Promptmallar
Spara egna AI-mallar för t.ex. veckoplanering eller e-post. Öppna dem via sidebaren eller med Ctrl+Space.
Simpel sparar all data lokalt på din dator — ingen molntjänst, ingen inloggning och inga konton.
